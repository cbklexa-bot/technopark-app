# Коптильня — быстрый запуск владельца

## Где находится рабочая ветка

Исходный проект: `cbklexa-bot/technopark-app`.
Рабочая ветка: `koptilnya-production`.

Не переносить этот код в `main` до проверки входа в общей Auth-системе, облачного сохранения после перезапуска и импорта Excel.

## Подключённая облачная база

Рабочая ветка: `koptilnya-production` в репозитории `cbklexa-bot/technopark-app`.

Миграция Коптильни применена к существующему Supabase-проекту ТехноПарка `cbklexa-bot's Project` (`ereiiidezagburttpxtn`, регион `eu-central-1`). Созданы объекты с префиксом `kp_`: 22 таблицы с включённым RLS и одно представление. Создан закрытый Storage bucket `koptilnya-private`. Миграция добавляла объекты Коптильни и не обновляла существующие таблицы `tp_*`. Проект `max-song-app` не используется.

Приложение использует общий сервис Supabase Auth проекта, но данные Коптильни хранятся отдельно и разрешаются через членство в организации. В Android-конфигурации используются только URL и публичный publishable key; service-role/secret keys нельзя помещать в приложение или публичный GitHub.

На изолированной тестовой базе миграция и 23 проверки PostgreSQL прошли успешно. Это не заменяет ручную проверку hosted Auth и Android на устройстве. После установки новой сборки проверь регистрацию, подтверждение email (если включено), вход, создание рабочей области, сохранение/повторное чтение данных и экспорт резервной копии.

## Настройка регистрации и восстановления пароля на Android

Приложение возвращает подтверждение почты и восстановление пароля через Android deep link:

`ru.koptilnya.app://auth/callback`

Один раз добавь этот адрес в **Supabase Dashboard → Authentication → URL Configuration → Additional Redirect URLs** проекта `ereiiidezagburttpxtn`. Сохрани настройки. **Не заменяй Site URL**: проект общий с «ТехноПарком», и изменение глобального адреса может сломать другие приложения. Для «Коптильни» адрес передаётся явно из приложения.

После установки APK:
1. Открой регистрацию и введи почту, пароль не короче 8 символов и название коптильни.
2. Открой самое новое письмо подтверждения. Android должен предложить открыть ссылку в «Коптильне».
3. Если аккаунт уже создан, но письмо просрочено, вернись на экран входа и нажми «Отправить письмо подтверждения повторно».
4. Для восстановления пароля введи почту, нажми «Восстановить пароль», открой новое письмо и задай новый пароль в открывшемся приложении.

Ссылка вида `http://localhost:3000/#error=...` относится к старой сборке/настройке и на телефоне работать не может. После установки обновлённого APK запроси новое письмо — старые ссылки уже могли истечь или быть использованы почтовым сканером.

## Импорт рабочей книги Excel

Импорт запускается кнопкой «Импорт Excel» после входа в аккаунт. Файл разбирается на устройстве. Перед заменой состояния приложения формируется ZIP-резервная копия; при ошибке сервера импорт не должен подтверждаться.

Распознаются листы:
- Продукция / Товары.
- Остатки / Остатки продукции.
- Клиенты / Контрагенты.
- Документы / Накладные.
- Позиции / Позиции накладных.
- Затраты / Расходы.
- Оплаты / Платежи.
- Партии / Производство / Выпуск.
- Контрольные суммы и расхождения.

Листы «Сводка», «Продажи», «Услуги» и «По месяцам» служат для сравнения и не импортируются как дополнительные операции. Они не должны повторно увеличивать выручку.

Активный справочник содержит ровно шесть названий:
`Тортика`, `Деревенька`, `Пекарня`, `Кочевник`, `Наш`, `Клиенты цеха`.
Другие имена остаются только в исторических реквизитах документов и не появляются в активном справочнике.

Импорт блокируется, если нет листа исходных документов, невозможно сопоставить позиции, имеются опасные повторы ключей или неоднозначно распределены платежи по повторяющимся номерам документов. Прежде чем разблокировать такой импорт, нужно сопоставить строки с оригиналом и не менять финансовые значения для прохождения тестов.

Годовые итоги 2025 и 2026 считаются из исходных документов; оплаченные суммы не прибавляются к выручке второй раз. Производственные партии, закупка сырья, выпуск продукции, расход запасов, продажи, себестоимость и дополнительные затраты считаются раздельно.
