# Коптильня — автономная версия

Рабочая ветка `koptilnya-local-licensing` заменяет прежний план облачного хранения автономным приложением.

- Для запуска не нужны Supabase, регистрация, email/SMTP или доступ к сети.
- Учётные данные хранятся локально в существующей базе WebView приложения.
- Excel импортируется на устройстве, после чего данные сохраняются через штатный локальный механизм приложения.
- Полный ZIP-экспорт включает базу JSON, Excel-отчёты, фотографии и вложения.
- Лицензии проверяются офлайн по ECDSA P-256. Открытый ключ встроен в приложение; закрытый ключ находится только в отдельном инструменте владельца.
- Ветка включает 7-дневный пробный период, лицензию на 30/90/180/365 дней и привязку ключа к Android ID.
- После окончания пробного периода/лицензии редактирование блокируется, но экспорт полной резервной копии остаётся доступным.

## Важное предупреждение о совместной инфраструктуре

Ранее подготовленная схема `kp_*` была применена к существующему Supabase-проекту, который обслуживает «ТехноПарк». Эта ветка удаляет Supabase-клиент из Android-приложения, но не пытается удалить удалённый проект или данные из него: они общие с другим приложением. Для автономной APK-сборки сетевой проект не требуется.

Автономная лицензия предназначена для практического контроля распространения, а не для защиты от продвинутого взлома устройства. Пробный период использует локальное состояние и Android ID, поэтому очистка данных приложения/переустановка может сбросить локальный trial state. Покупная лицензия подписана криптографически и не может быть подделана без закрытого ключа.
